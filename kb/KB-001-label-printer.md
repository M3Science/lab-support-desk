# KB-001: Specimen label printer not printing or printing blank

| Applies to | Typical priority | First owner | Escalate to |
|---|---|---|---|
| Collection sites, lab receiving | P3 (P2 if a whole site cannot label) | Tier 1 | Tier 2 (printer mapping), facilities/IT (hardware) |

## Symptoms
- Labels do not print after the order is released.
- Labels print blank, faded, or with missing barcode lines.
- Labels print at a different workstation's printer.

## Before you start
- Ask which workstation and printer name the user is on.
- Ask whether other users at the same site are affected (site-wide = raise priority).
- Remind the user to use downtime labels if patients are waiting (KB-008).

## Steps
1. Check the printer for a paper jam, open lid, or error light. Clear it and power-cycle.
2. If labels are blank or faded, replace the ribbon and label stock; confirm the stock type matches the printer.
3. Print a test label. Scan the barcode with a handheld scanner to confirm it reads.
4. If labels print elsewhere, check the workstation's default label printer mapping and correct it.
5. Reprint the affected labels and confirm with the user before closing.

## Escalate when
- The printer is mapped correctly but still receives nothing (Tier 2: print queue or device mapping).
- Barcodes print but will not scan (Tier 2: label format).
- Hardware fault after ribbon and stock replacement (facilities/IT).

## Close the ticket with
Printer name, root cause (jam / ribbon / stock / mapping / hardware), labels reprinted Y/N.
