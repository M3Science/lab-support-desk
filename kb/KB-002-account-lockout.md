# KB-002: Account locked out or password expired

| Applies to | Typical priority | First owner | Escalate to |
|---|---|---|---|
| All LIS users | P3 (P2 if the user is the only tech on a bench) | Tier 1 | Tier 2 (security role problems) |

## Symptoms
- "Account locked" or "password expired" at login.
- User can log in to the workstation but not to the LIS.

## Before you start
- Verify identity per the identity-verification policy before any reset. Never reset for a caller you cannot verify.
- Never ask for, write down, or share the user's password.

## Steps
1. Confirm the username and verify identity.
2. Unlock the account or issue a temporary password per the reset procedure.
3. Stay on the line while the user logs in and sets a new password.
4. If lockouts repeat, ask whether a saved password on another device is retrying the old one.

## Escalate when
- The user logs in but is missing menus or functions (security role, see KB-009).
- Several users are locked out at once (possible directory or authentication outage: raise to P1/P2).

## Close the ticket with
Username, lockout vs expired, verified login Y/N. Do not record passwords.
